## 不只是一个主页

crazyczy.com 是我的双语个人网站，也是一个持续演进的数字空间。它承载技术文章、项目记录和个人介绍，同时保留一些更有玩心的入口：贪吃蛇、星际飞行，以及可以用命令浏览网站的 Terminal。

首页和列表页面使用像素字体，形成明确的视觉性格；文章正文切换到更适合长时间阅读的衬线字体。亮色主题以暖米黄色为底，暗色主题使用纯黑高对比界面，首次访问跟随系统设置，也允许访客保存自己的选择。

## 内容与路由

中文和英文内容可以独立发布，通过共同的 translationKey 建立关联。文章由 Markdown 文件维护，构建时生成博客列表、标签页、RSS、站点地图以及搜索引擎所需的 canonical、hreflang 和结构化数据。

这种结构不要求每篇文章必须同时拥有译文，但当译文存在时，语言切换可以直接到达对应内容。它让双语不是两套互不相干的网站，而是一组可以逐步补全的内容关系。

## 静态优先的工程选择

网站使用 React 与 Vinext 构建，并部署在 Cloudflare 上。代码推送到 GitHub 的 main 分支后，会自动完成检查、构建和发布。站点不需要数据库、登录、追踪脚本或单独购买证书，游戏最高分与主题偏好只保存在访客自己的设备上。

选择静态优先并不是为了追求最少功能，而是为了降低长期维护成本。一个个人网站真正困难的部分往往不是首次上线，而是几年以后仍然愿意更新。这个仓库既保存网站代码，也通过 README 说明本地开发、内容结构和发布流程，让未来的维护者——包括未来的我——更容易重新进入项目。
